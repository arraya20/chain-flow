What this page does

This reviewer companion calculates a decision from values entered below. It does not call Chain MCP or invoke the Skill Engine. Supplied observations are not independently verified.

For a genuine agent run, follow SKILL.md and use the installed Pharos Skill Engine and official Chain MCP. This flow never signs or broadcasts transactions.

Agent flow

  1. One request loads the installed readiness Skill.
  2. The Skill obtains balance, gas price, and gas estimate from Chain MCP in the same run.
  3. The Skill passes those observations and the request constraints to the exact-arithmetic evaluator, then checks its result.
