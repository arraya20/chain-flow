Pharos Transfer Readiness

Get a fresh Pharos Chain MCP observation set and check whether it covers a PROS transfer, estimated gas, and retained reserve.

Live, read-only check

Each submission calls the official public Pharos Chain MCP server for the latest block, sender balance, gas price, and transfer gas estimate. It does not sign or broadcast transactions.

This dashboard performs the live MCP read and deterministic calculation. The separate agent composition is described in SKILL.md; this page does not itself run an agent or invoke the Skill Engine.

Live evaluation sequence

  1. Enter the sender, recipient, transfer amount, and reserve.
  2. The server creates a project run ID and queries Chain MCP for a block, pinned balance, gas price, and estimate.
  3. The evaluator calculates readiness and returns the block time plus the actual fetch time.
